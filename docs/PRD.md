# kosdap — 삼성전자/SK하이닉스 추정가 서비스 PRD

## 1. 목표
삼성전자(005930)와 SK하이닉스(000660)의 **국내 장(KRX) 마감 이후 ~ 다음 거래일** 추정가격을 계산해서 보여주는 웹사이트.

추정가격은 LLM이 임의로 생성하는 것이 아니라, **실시간 시장 데이터를 수집해 정량적으로 계산**한다. 계산 로직은 초기엔 사람이 정한 가중합(weighted score)으로 시작하고, 예측 이력이 쌓이면 LightGBM/XGBoost로 가중치를 자동 학습하는 방향으로 고도화한다.

## 2. 핵심 차별점
1. **예측 근거를 투명하게 공개** — 상승요인/하락요인을 항목별로 나열
2. **예측 정확도를 스스로 기록·공개** — 예측 vs 실제, MAPE/RMSE를 매일 자동 계산해서 숨기지 않음
3. **주말/장마감 구간도 실데이터 기반으로 추정** — 아래 "3. 핵심 데이터 소스" 참고

## 3. 핵심 데이터 소스

### 3.1 1차 신호 — 토큰화 주식 / 무기한선물 (24/7 실거래)
과거엔 "국내 장이 닫히면 추정할 방법이 없다"는 게 문제였으나, 2026년 SK하이닉스 나스닥 ADR 상장 이후 크립토 거래소에 아래 상품이 상장되어 **주말을 포함한 24/7 실시간 가격 신호**로 사용 가능:

| 종목 | 상품 | 티커 | 특징 |
|---|---|---|---|
| SK하이닉스 | Binance bStocks (1:1 담보 토큰) | SKHYB/USDT | 커스터디언이 실주식 1:1 보유, 거래대금이 실주식의 ~80% 수준으로 유동성 양호. **1순위 신호** |
| SK하이닉스 | xStocks | SKHYX/USDT | SKHYB보다 시총 작음, 보조 신호 |
| 삼성전자 | 무기한선물(perpetual futures) | SMSN/USD (Hyperliquid), Bybit/Binance 상장 | 1:1 담보 토�큰은 아직 없음. 최대 20배 레버리지 상품이라 SKHYB 대비 괴리(베이시스)가 클 수 있음 — 보정 필요 |

**베이시스 보정**: 매 KRX 장마감 시점에 (토큰가 − KRX 종가) 오프셋을 계산해 저장하고, 다음 추정 시 그 오프셋을 반영해 괴리를 보정한다.

### 3.2 2차 신호 — 해외 상관 종목 (보조 설명 요인)
- Micron (MU) — 메모리 동종업계 최근접 지표
- Nvidia (NVDA) — HBM 수요 (SK하이닉스 상관도 특히 높음)
- SOXX / SMH — 반도체 업종 지수
- TSMC (TSM) — 글로벌 파운드리 사이클
- 나스닥/S&P 선물 — 전체 위험자산 심리
- KOSPI200 야간선물(Eurex) — 한국 지수 자체의 해외 시간대 신호
- USD/KRW, DXY, 미국 10년 국채금리, VIX — 매크로 팩터
- BTC/ETH — 보조 리스크 센티먼트 (가중치 낮게)

### 3.3 3차 신호 — 국내 수급 (일 단위 지연 데이터, 실시간 아님)
- 공매도비율, 외국인/기관 순매수 — **하루 1회 장마감 후 갱신**되므로 다음날까지는 고정값으로 취급 (10분마다 조회해도 값이 안 바뀜에 유의)

### 3.4 KRX 자체 시간외 데이터 (추정이 필요 없는 구간)
- 장후 시간외 단일가 (16:00~18:00): 실제 체결가이므로 "추정"보다 우선
- 장전 시간외 (07:30~08:30): 동일

## 4. 계산 로직

### 4.1 초기 (수동 가중치)
```
score = 0.35 * (SKHYB/SMSN 토큰 변동률, KRX종가 베이시스 보정)
      + 0.30 * (동일 종목의 짝 토큰... 실제로는 종목별로 자기 자신의 토큰만 사용)
      + 0.10 * Nvidia 변동률
      + 0.05 * Micron
      + 0.05 * SOXX
      + 0.03 * BTC
      + 0.03 * ETH
      + 0.02 * DXY
      + 0.02 * USDKRW
      + 0.02 * VIX
      + ... (국내 수급 팩터, 낮은 가중치)
```
> 종목별로 "자기 자신의 토큰화 가격"이 1차 신호이며, 삼성전자 계산엔 SMSN 토큰을, SK하이닉스 계산엔 SKHYB 토큰을 사용한다. (PRD 초안의 "Token 삼성전자 0.35 + Token 하이닉스 0.30" 표현은 오해 소지가 있어 종목별로 분리함)

### 4.2 고도화 (ML)
- 데이터가 충분히 쌓이면(최소 수개월) LightGBM/XGBoost로 가중치를 자동 학습
- 손실함수: quantile loss로 학습해 점추정 대신 **예측 구간(신뢰구간)**을 함께 산출
- **요일별 모델 분리**: 금요일→월요일(주말 포함, 해외 영향 큼) vs 평일→익일(국내 수급 영향 큼)

### 4.3 백테스트 (출시 전 필수)
서비스 오픈 전, 과거 1~2년치 데이터로 위 계산식을 백테스트해서 실제 예측력이 있는지 검증한다. 초기 "정확도 xx%" 표시는 이 백테스트 결과를 사용한다 (실운영 이력이 쌓이기 전까지 가짜 숫자를 보여주지 않는다).

## 5. 화면 구성

### 5.1 메인 (`/`)
삼성전자 카드 + SK하이닉스 카드, 각각:
- 현재 종가 (KRX 정규장 또는 최근 시간외 체결가)
- 추정가격, 등락률
- 상승확률, 신뢰도
- 예상 변동폭 (예측 구간: 82,900 ~ 83,500)
- 영향요인 목록 (🟢/🔴 + 기여도)
- 차트 (Chart.js)

### 5.2 예측 기록 (`/history`)
최근 100일: 예측가격 / 실제가격 / 오차(%) / 누적 정확도(최근 30일·100일) / 평균오차 / RMSE / MAPE

### 5.3 관리자 (`/admin`)
- 데이터 새로고침 (수동 트리거)
- 예측 다시 계산
- API 상태 (각 데이터 소스별 최근 수집 성공/실패)
- 로그

## 6. 수집 주기
데이터 소스마다 실제 갱신 빈도가 다르므로 일괄 10분 주기가 아니라 **소스별로 다르게** 스케줄링한다.

| 소스 | 주기 | 비고 |
|---|---|---|
| SKHYB/SMSN 토큰가 | 5~10분, 24/7 | 주말에도 계속 수집 |
| 미국 주식(MU/NVDA/SOXX/TSM) | 5~10분, 미국 정규장+애프터마켓 시간대만 | 미국장 휴장 시간엔 정지 |
| KOSPI200 야간선물 | 5~10분, Eurex 운영시간 | |
| 환율/DXY/VIX | 10~15분 | |
| 공매도비율/수급 | 1일 1회 (장마감 후) | |
| KRX 시간외 단일가 | 실시간 (해당 세션 중) | |

**주말 처리**: 금요일 KRX 마감 후 ~ 다음 CME/Eurex 재개 전까지는 SKHYB/SMSN 토큰가가 유일한 실시간 신호. 이 구간은 "주말 모델"(요일별 분리 모델)로 별도 취급하고, 2차/3차 신호는 금요일자 값으로 고정(carry-forward).

모든 페이지 하단에 "본 정보는 투자 참고용이며 투자자문·권유가 아닙니다" 디스클레이머 표기.

## 8. 기술 스택
- **웹**: Next.js 15 (App Router) + React + TypeScript + TailwindCSS + shadcn/ui + Chart.js
- **데이터/ML**: Python (수집기 + 회귀/LightGBM/XGBoost)
- **DB**: Supabase (Postgres)
- 역할 분리: Python이 수집·계산·저장까지 담당, Next.js는 Supabase를 읽어서 보여주는 역할 + 관리자 트리거용 API
